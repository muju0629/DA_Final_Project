# 청년 실업률, 공식 지표 밖을 보다

**청년층 공식 실업률의 측정 범위 확장·재계산과 실제 고용 어려움에 영향을 미치는 요인 분석**

> 2026년 9월 기준 청년(15~29세) 공식 실업률은 5.4%, 확장실업률(고용보조지표3)은 15.6%입니다.
> 10%p가 넘는 이 차이는 표본오차로 설명되지 않습니다. 이 프로젝트는 공식 실업률이 "틀렸다"가 아니라
> **"정의상 좁고, 그 바깥에 있는 청년이 늘고 있다"**는 점을 데이터로 보여주는 것을 목표로 합니다.

## 2. 지표 정의

국가데이터처 통계설명자료 기준입니다.

| 지표 | 계산식 |
|---|---|
| 공식 실업률 | 실업자 ÷ 경제활동인구 × 100 |
| 고용보조지표1 | (시간관련추가취업가능자 + 실업자) ÷ 경제활동인구 × 100 |
| 고용보조지표2 | (실업자 + 잠재경제활동인구) ÷ 확장경제활동인구 × 100 |
| 고용보조지표3 | (시간관련추가취업가능자 + 실업자 + 잠재경제활동인구) ÷ 확장경제활동인구 × 100 |
| **확장지표4 (자체)** | 보조3 분자 + 잠재경활에 포함되지 않은 '쉬었음' (분모도 동일하게 확장) |
| **확장지표5 (자체)** | 확장지표4 + 비경활 취업준비자 (중복 제거) |

- 잠재경제활동인구 = 잠재취업가능자 + 잠재구직자
- 확장경제활동인구 = 경제활동인구 + 잠재경제활동인구
- 확장지표 4·5는 개인 단위로 **상태를 하나씩만 배정**해야 이중 계산을 피할 수 있으므로 원자료로 계산합니다.

계산 코드는 [`src/indicators.py`](src/indicators.py)에 있습니다.

### X-13 계절조정 설정
`statsmodels`의 X-13은 미국 센서스국 실행파일을 호출하는 래퍼입니다. `requirements.txt`의 `x13binary`가 실행파일을 함께 설치하며, 경로를 `X13PATH` 환경변수로 지정합니다. 설치가 안 되면 `statsmodels.tsa.seasonal.STL`로 대체하고 발표에서 그 사실을 명시합니다.

## 7. 주의사항 (분석 원칙)

1. **분석 기간은 2015.1~2026.8로 고정합니다.** 2026년 9월부터 제8차 KSCO·제11차 KSIC가 적용되어 직종·산업 시계열이 이어지지 않습니다.
2. **원자료 가중치:** 월자료 `weight / 1000`, 연자료(12개월 합) `weight / 12000` → 천 명 단위 공표치와 일치해야 합니다.
3. **공표치 검증 기준:** 재계산값과 공표값 차이가 ±0.1%p(반올림 오차) 이내여야 합니다. 넘으면 연령 기준(만 나이)과 변수 정의부터 점검합니다.
4. **AI 파트는 인과를 주장하지 않습니다.** AI 노출도는 재택근무 가능성과 상관이 높아(한국은행, ρ=0.74) 교란 요인이 있습니다. "노출 상위 직업에서 청년이 상대적으로 더 줄었다"까지만 말합니다.
5. **수치 인용은 1차 자료로만 합니다.** 언론 보도 수치는 국가데이터처·한국은행 원문과 대조한 뒤 씁니다.

## 다운로드 후 기록할 항목

각 자료의 원문 URL, 조회일, 제공 기간, 분류 차수, 단위, 계절조정 여부와 실제 파일명을 기록한다. MDIS는 연도별 변수명·코드값·결측값 정의·가중치 배율을 남긴다. 직업 연결표에는 일대다 처리 규칙과 미연결 비중을 기록한다.
